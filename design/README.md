# Figma exports

Place the exported designs for this project in this folder:

- `landing.png`, `plp.png`, `pdp.png`, `checkout.png` (desktop and mobile frames)
- `design-tokens.png` (typography + color token board)
- `figma-link.txt` (link to the Figma file, set to "can view")

Token names in Figma match the CSS variables in `src/styles/tokens.css`.
